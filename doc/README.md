## 🎮 핵심 컨셉 요약 (Pivot Summary)

- **장르**: 실시간 주식 정보 시각화 방치형 RPG (Idle Stock Market Visualizer RPG)
- **플랫폼 & 화면**: Android 모바일 세로 모드 (FHD+ 1080×2400)
- **패키지 식별자**: `com.ddan.stockrpg`
- **주요 특징**:
  1. **단일 플레이어 유형 (개미 투자자)**: 복잡한 5인 다중 캐릭터/가챠 배제 ➔ 단 1명의 주인공 개미를 집중 육성 및 100% 자율 사냥
  2. **192종목 초대형 오픈월드 증시 맵**: 한·미 각 96종목(총 192종목) 지원. 섹터 거리 8,000px, 성역 간격 995px의 쾌적한 8방위 네온 고속도로 크루즈 이동
  3. **살아있는 주식 정보 시각화**: 오늘 오른 종목(▲)은 붉은 상승 캔들로, 내린 종목(▼)은 푸른 음봉 캔들로 전장에 실시간 투영
  4. **변동성 완화장치(VI) 및 스마트 순회 AI**: 과열 종목 10분(600초) 단일가 냉각(VI) 발동 시 즉시 이탈하며 10분간 거래정지 및 타겟 제외, 일반 종목 5분(300초), 섹터 90초 쿨타임으로 전 섹터 골고루 자동 순회
  5. **계단식 보스전 난이도 밸런스**: 무한 시간 비례 강화가 아닌 '트럼프 보스 격파 시점'에만 적 능력치가 계단식으로 상승하여 공정한 파밍 템포 보장
  6. **실시간 주식 속보 돌발 이벤트**: 상단 MTS 뉴스 타전 시 개미 주변에 3~5분 한정 돌발 이벤트 포털/보물상자 즉시 생성
  7. **MTS 세로 UI & 편의 컨트롤**: [국장/미장], [AUTO/수동], [🔊소리/🔇음소거], [⚡1X/2X/3X] 배속 제어 및 사운드 스로틀링 최적화
  8. **방치 & 배당금 시스템**: 사냥 골드로 우량주(삼성전자, 하이닉스, 엔비디아 등)를 매수하면 위성 오브로 공전하며 시간당 배당금 자동 누적

## 🚀 빠른 시작 (Quick Start)

```bash
# 1. Godot 프로젝트 헤드리스 검증
godot --headless --quit-after 50

# 2. 안드로이드 APK 빌드
make build

# 3. 연결된 디바이스에 설치 및 실행
make install
```
